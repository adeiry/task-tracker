# My Personal AI Usage Rules

## Rule 1 - What I will never paste

I will never paste real customer data, personal data, production data, regulated data, confidential external data, credentials, API keys, tokens, or private service information into an AI tool.

## Rule 2 - What I will always verify before accepting

Before accepting AI-generated work, I will inspect it, verify it using the appropriate tests or tools for that artifact, and make sure I understand any important logic before considering it complete. If I cannot explain the code or recommendation, I will review it further before accepting it.

## Rule 3 - How I will record AI contributions

For every significant AI-assisted task, I will record the prompt, the generated output, the changes I accepted or rejected, and the verification I performed in my prompt log files so the AI contribution remains transparent and traceable.
